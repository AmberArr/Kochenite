# Kochenite

Native, local-first Android bookkeeping project. Currently at the Phase 1
build-system decision gate; this repository contains a **synthetic-only proof**,
not an app ready for financial records.

- [Toolchain capability matrix, limitations and commands](docs/toolchain-proof.md)
- [Master plan](.agents/plans/PLAN.md)
- [Phase 1 plan and verification status](.agents/plans/phases/01-foundation.md)

Use the pinned `./kotlin` wrapper from the repository root with default caches.
Only physical-device testing is permitted on this host. No recognition service
or financial ledger is implemented yet.
